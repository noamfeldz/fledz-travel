# תוכנית מימוש לאתר הטיול בלונדון

## מה האתר כולל
- רשימת מקומות עם חיפוש, סינון ושמירה.
- הזנת מלון לצורך חישוב מרחקים וזמני הגעה.
- מפה של המלון והמקומות השמורים.
- תכנון יומי עם סדר מקומות וחיווי אם היום נוח מבחינת נסיעות.
- מסך ניהול פשוט להוספת מקומות ידנית.

## תחבורה ציבורית
- זמן הגעה משוער מהמלון לכל מקום.
- דרך הגעה מומלצת: הליכה, אוטובוס, רכבת תחתית או שילוב.
- תחנה קרובה לכל מקום כשיש מידע כזה.

## הערות
- זהו שלב ראשון פשוט ושימושי, בלי ניווט חי בזמן אמת.
- אפשר בהמשך להוסיף שיתוף, עבודה בלי אינטרנט ופיצ'רים חכמים יותר.
