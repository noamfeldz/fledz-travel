# Flight block backgrounds

These images are used as the calendar flight-block backgrounds (see `.planner-cal-block--outbound` / `--return` in `src/index.css`).

Save two photos here with these exact names:

- `departure.png` — outbound / departure flight (the bright **daytime blue-sky** window view)
- `arrival.png` — return / arrival flight (the **sunset** window view)

To swap which photo goes where, just swap the two filenames. Landscape images work best (they're shown `background-size: cover`). If you change the extension, update the `url(...)` paths in `src/index.css`.
